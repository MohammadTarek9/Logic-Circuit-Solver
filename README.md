# Logic-Circuit-Solver

This project is a logic circuit solver using c++ which handles multi-level logic gates and expressions while also providing different mechanisms for error handling.

## Supported Gates
1. AND
2. OR
3. XOR
4. NAND
5. NOR
6. NOT
